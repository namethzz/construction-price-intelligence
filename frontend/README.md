# Construction Price Intelligence — Frontend

React + Vite frontend prototype for the Construction Price Intelligence project.

## Run

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Notes

- Current data is mock/demo data.
- The frontend is structured so FastAPI endpoints can be connected later.
- Main pages: Overview, Prices, Forecast, Analysis, Cost Planner, Data & Statistics.
